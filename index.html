Nim in the browser

Nim 2.2.4 runs here as WebAssembly, and compiles your program either to C — which Clang 22 turns into WebAssembly, using the same toolchain LiveCodes uses for C/C++ and Objective-C — or straight to JavaScript, which runs in a sandboxed frame. Nothing is sent to a server.
